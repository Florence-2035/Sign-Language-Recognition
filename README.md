# Real-Time Sign Language Recognition Translator Using AI

A computer vision project that explores real-time hand gesture recognition using a webcam, Python, OpenCV, and MediaPipe.

## Project Overview

The project captures live video, detects hand landmarks, and processes hand gestures using Python logic. It aims to explore how AI and computer vision can help make gesture-based communication more accessible.

## Technologies Used

- **Python** — gesture processing and application logic
- **OpenCV** — webcam access and video processing
- **MediaPipe** — hand detection and landmark tracking

## How It Works

1. Capture live video from a webcam.
2. Process video frames using OpenCV.
3. Detect hand landmarks using MediaPipe.
4. Process the detected landmarks using Python gesture logic.
5. Display the output supported by the implemented gestures.

## Current Status

This project is a learning prototype for real-time hand gesture recognition. Recognition capabilities depend on the gestures implemented in the current code.

## Future Improvements

- Expand the set of recognized gestures.
- Improve recognition accuracy under different lighting conditions.
- Develop a user-friendly interface.
- Explore support for additional sign-language gestures.
