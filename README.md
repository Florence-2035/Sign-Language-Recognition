# Real-Time Sign Language Recognition Using AI

A computer vision project that uses a webcam to detect hand gestures and explore real-time sign language recognition.

## Overview

This project aims to make communication more accessible by recognizing hand gestures through a camera feed. It combines computer vision and a simple interactive interface to demonstrate gesture recognition.

## Technologies Used

- **Python** — core programming language
- **OpenCV** — webcam access and image processing
- **MediaPipe** — hand landmark detection, if enabled in the current implementation
- **Streamlit** — interactive application interface

## Features

- Real-time webcam input
- Hand detection and landmark visualization
- Gesture recognition for the gestures supported by the current model or implementation
- Interactive interface for displaying recognition results

## Getting Started

### Prerequisites

- Python installed on your computer
- A working webcam
- Git installed if you want to clone the repository

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Florence-2035/Sign-Language-Recognition.git
   ```

2. Open the project folder:

   ```bash
   cd Sign-Language-Recognition
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application using the command appropriate to the implementation:

   ```bash
   streamlit run app.py
   ```
